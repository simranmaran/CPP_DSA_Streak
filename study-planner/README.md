# Zero to C++

A 3-day C++ and DSA starter planner: Friday, Saturday and Sunday plans, lessons, focus timer, daily habits, quiz, notes and a squad progress board.

## Run
Open `index.html` in a browser. No build step, no install.

## Files
- `index.html`: page structure
- `styles.css`: colors, fonts and layout (theme tokens are at the top, light and dark)
- `app.js`: plan data (`PLAN`), lessons (`L`), quiz questions (`QZ`) and all behaviour

## Edit the plan
- Add or change tasks in the `PLAN` array in `app.js`.
- Add lesson text for a task title in the `L` object.
- Add quiz questions to `QZ`.

Progress is saved in the browser (`localStorage`). Squad data is stored on the same device only.
